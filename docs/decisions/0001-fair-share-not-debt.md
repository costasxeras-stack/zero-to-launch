# 0001: A fair-share rule instead of a running debt

**Status:** accepted, 0.1.0

## Context

Split apps frame a partner as a debtor, and splitting had the lowest ratings in the review proxy.

## Decision

Show each partner's share against an agreed rule (50/50 or by income) and phrase gaps without blame.

## Tradeoff

- Less precise than line-by-line splitting
- Matches how couples talk about money, to be confirmed in tests
